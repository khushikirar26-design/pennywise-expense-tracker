
# PennyWise — Expense Tracker

## Description

PennyWise is a personal expense tracking web application built using React.js, JavaScript, HTML, and CSS. It helps users manage their income and expenses, monitor their balance, and understand their spending habits through a simple and user-friendly dashboard.

The application stores user data in the browser's localStorage, allowing saved information to persist across page refreshes on the same browser.

## Features

- **Dashboard:** View your income, expenses, and available balance.
- **Income Management:** Track income and regular monthly income.
- **Expense Tracking:** Add and manage expense transactions.
- **Monthly Reports:** View monthly financial summaries and category-wise spending.
- **Yearly Reports:** Compare income and expenses across months.
- **Transaction Management:** Search, filter, and delete transactions.
- **Category Breakdown:** Understand where your money is being spent.
- **Profile Settings:** Manage profile details and display currency preferences.
- **Local Storage:** Preserve saved data in the browser.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Visual Studio Code (recommended)

### Installation

**Step 1: Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Navigate to the project folder**

```bash
cd pennywise-expense-tracker
```

**Step 3: Install dependencies**

```bash
npm install
```

**Step 4: Start the development server**

```bash
npm start
```

Open http://localhost:3000 in your browser to use the application.

## How It Works

1. Add your income and expense transactions.
2. View your available balance on the dashboard.
3. Review monthly and yearly financial reports.
4. Search, filter, or delete transactions as needed.
5. Refresh the page; saved data remains available in the same browser unless its local storage is cleared.

## Data Storage

PennyWise currently uses browser localStorage for data storage. It does not currently use a backend server or a centralized database, so data is not automatically synchronized between devices or browsers.
